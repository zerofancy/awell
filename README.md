# AWell

将本地目录中的照片显示为动态壁纸。先绘制黑底和 10 个随机彩色矩形，再居中等比绘制照片；每次解锁同步更新照片与矩形背景，不定时刷新。

## 使用

1. 打开应用，点击“选择照片目录”，在系统选择器中授权一个本地文件夹。
2. 应用递归读取所有可访问子目录的图片。只申请持久读取权限，不修改原始文件。
3. 点击“设置动态壁纸”，在系统预览中应用。
4. 解锁后随机换图；多张照片避免连续重复，单图目录保持照片但刷新背景。照片留白和透明区域显示矩形背景。

目录授权可跨应用进程重建和设备重启保留。目录失效时可重新选择；空目录显示矩形背景，临时读取失败保留上一组画面。返回桌面或调整屏幕尺寸不会随机换图。无安全锁屏及厂商锁屏的解锁广播行为需要在目标设备验证；服务未运行期间无法回补历史解锁。

## 验证

Release 默认通过系统钥匙圈签名，首次配置见 [Gradle 钥匙圈签名说明](docs/keyring-signing.html)。配置完成后直接运行 `./gradlew :app:assembleRelease`。

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
./gradlew :app:connectedDebugAndroidTest
```

单元测试覆盖递归深层目录、循环和重复文档、不可读子目录、取消传播、随机选择与过期请求。设备测试覆盖真实 SAF 持久授权、递归读取、授权释放与恢复、照片方向和采样、界面入口、同步换图及预览隔离。SAF 测试使用测试 APK 自带提供者与独立配置，不操作用户照片或应用的实际目录配置。

完整验收还需按 Spec 在目标设备完成：通过系统选择器配置真实目录并应用壁纸，连续锁屏解锁、仅亮屏不解锁、返回桌面、等待超过 120 秒、重启设备，以及撤销目录权限。自动测试中的解锁事件通过协调器注入，不能替代系统锁屏广播与实际壁纸 Surface 的端到端验收。
